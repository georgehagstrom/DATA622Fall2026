Problem 1: kNN Classification of the ZIP code digit data

In order to complete this problem you will need to download zip.train and zip.test from the course github page. These datasets contain images of hand-drawn digits. We will be experimenting with kNN classification and factors impacting the bias-variance trade-off, and this will also be chance to practice using scikit-learn.

  1. Log Loss: Another metric for judging the quality of a classification model is called the log loss (also called the log score or cross entropy; lower is better). Log loss penalizes overconfident wrong predictions much more heavily than accuracy. The purpose of log loss is to estimate the probability of an unknown sample being in each class, rather than to predict just the most likely class. You can apply log loss using the log_loss function built into sklearn as follows:
from sklearn.metrics import log_loss

knn = KNeighborsClassifier(n_neighbors=4)
knn.fit(zip_image_train, zip_class_train)

zip_prob_train = knn.predict_proba(zip_image_train) # Notice how we are predicting probabilities here not the class
loss_train = log_loss(zip_class_train, zip_prob_train, labels = knn.classes_)
print(f'loss_train: {loss_train:.4f}')

zip_prob_test = knn.predict_proba(zip_image_test)
loss_test = log_loss(zip_class_test, zip_prob_test, labels = knn.classes_)
print(f'loss_test: {loss_test:.4f}')

  2. A very different dataset from the zip digit data is the Abalone dataset. This dataset originated from a fisheries study and later became a benchmark dataset in the UCI machine learning repository. The dataset contains information on the physiological characteristics of abalone (a type of shellfish) and their shells, with variables that include their sex, length (also diameter and height), weight (of the different components), and rings (which corresponds to age). The code below downloads this data and trains a kNN model to predict sex. Individuals fall into three categories, male (M), female (F), and indeterminable/immature (I).

from sklearn.datasets import fetch_openml
from sklearn.model_selection import train_test_split
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler

abalone = fetch_openml(name="abalone", version=1, as_frame=True, parser="auto").frame
abalone_features = abalone.drop(columns=["Sex", "Class_number_of_rings"])
abalone_sex = abalone["Sex"]

X_train, X_test, y_train, y_test = train_test_split(abalone_features, abalone_sex, test_size=0.5, stratify=abalone_sex, random_state=1001)

# It is a good idea to standardize features when using kNN. It doesn't really matter here very much but I do it anyways

knn = make_pipeline(StandardScaler(), KNeighborsClassifier(n_neighbors=4))
knn.fit(X_train, y_train)

sex_pred_train = knn.predict(X_train)
accuracy = accuracy_score(y_train, sex_pred_train)
print(f'Accuracy: {accuracy:.4f}')

sex_pred_test = knn.predict(X_test)
accuracy = accuracy_score(y_test, sex_pred_test)
print(f'Accuracy: {accuracy:.4f}')
